# Aprendizado de Máquina

Materiais, exercícios e notebooks da disciplina de Aprendizado de Máquina.

## Conteúdo

- `aula1/exercicios.ipynb`: pipeline completo de machine learning com o dataset Iris, incluindo exploração, preparação, treino com k-NN e avaliação.
- `aula2/aula2.ipynb`: preparação e auditoria de dados, codificação de variáveis categóricas e regressão com o dataset Bank Marketing.
- `aula1/IASEG ML C1a.pdf` e `aula1/IASEG ML C1b.pdf`: materiais de apoio da primeira aula.
- `Projeto_disciplina.pdf`: enunciado do projeto da disciplina.

## Como executar

1. Crie e ative um ambiente virtual Python.
2. Instale as dependências:

   ```bash
   pip install -r requirements.txt
   ```

3. Inicie o Jupyter:

   ```bash
   jupyter notebook
   ```

4. Abra o notebook da aula desejada.

O notebook da Aula 2 baixa o dataset Bank Marketing a partir de uma URL pública durante a execução.
